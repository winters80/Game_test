# Aethoria / Verath — Structured Audio Prompt Pack

This archive contains all 32 audio and TTS voice specifications organized for batch generation pipelines.

## Directory Structure
- `ambience/` — 6 seamless 30-second ambient loop prompts (no music)
- `sfx/` — 10 short sound effect prompts (~0.8s–2.0s, no music)
- `music/` — 5 instrumental music loop prompts (75s–90s, with target BPM)
- `voice/core_cast/` — 7 Core Cast & System TTS voice profiles and sample lines
- `voice/bot_adventurers/` — 4 Bot Adventurer runtime TTS preset profiles and example lines
- `manifest.json` — Machine-readable master manifest for API / script ingestion
- `manifest.csv` — Flat spreadsheet-compatible manifest of all 32 assets
